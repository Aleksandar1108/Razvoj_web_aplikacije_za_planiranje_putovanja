Uputstvo za pokretanje 

- Backend:
Otvoriti Visual Studio kao administrator, zatim open project odaberemo naš projekat. Kada se sve učita pokrećemo backend tako što kliknemo Run (gore zelena strelica)

-Frontend:
Otvorimo projekat u Visual Studio Codu, zatim naredba cd client, zatim npm install(samo prvi put kada se preuzme projekat), i nako toga npm run dev 

Što se tiče baze prvo pokrecemo Docker, zatim ulazimo u Microsoft SQL Menagement Studio i konektujemo se na bazu
